# Кофеин — вариант «Город»

Учебный проект: PHP 8.2+, MySQL 8.x, Bootstrap 5, JavaScript Fetch API.
Оформление отличается от исходного варианта; маршруты и правила доступа сохранены.

## Просмотр без установки
Откройте preview/login.html в браузере. Ссылки «Далее» показывают шесть экранов.
Это статические снимки интерфейса в HTML с демонстрационными данными. Формы не сохраняют данные.
Bootstrap загружается из CDN, поэтому для оформления нужен интернет.

## Полноценный запуск
1. Установите PHP с pdo_mysql и mbstring, запустите MySQL.
2. Создайте базу SQL-командой:
   CREATE DATABASE kofein_city CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
3. Скопируйте config.example.php в config.php и укажите реквизиты MySQL.
4. Из корня проекта: php database/migrate.php
5. Запустите: php -S 127.0.0.1:8000 -t public public/router.php
6. Откройте http://127.0.0.1:8000/register, зарегистрируйтесь и войдите.

## Проверки
node tests/smoke.mjs http://127.0.0.1:8000
Полный тест после подключения отдельной учебной базы:
node tests/integration.mjs http://127.0.0.1:8000
Интеграционный тест создаёт два тестовых аккаунта и записи.
Полная работа с MySQL в окружении подготовки отчёта не проверялась.

## Публикация
Не загружайте config.php с паролями. Он исключён из Git.
Корень сайта Apache должен указывать на public, необходим mod_rewrite.
Для локального запуска достаточно встроенного PHP-сервера.
